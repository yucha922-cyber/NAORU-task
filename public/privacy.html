NAORU TASK

プライバシーポリシー

制定日: 2026年11月9日

NAORU TASK（以下「本アプリ」）は、NAORU整体のスタッフが業務タスクを管理するための社内向けウェブアプリです。本アプリにおける利用者情報の取り扱いを以下のとおり定めます。

1. 取得する情報

  • アカウント情報: メールアドレス、表示名、パスワード（パスワードは認証基盤により安全に保管され、運営者も閲覧できません）
  • 業務情報: タスクの内容、期限、担当者、完了状況、操作履歴、所属店舗・権限
  • Googleカレンダー連携を利用する場合: 連携したGoogleアカウントのメールアドレス、本アプリが作成したカレンダーおよび予定のID、同期の状態

患者様の氏名・症状などの医療情報や個人情報は、本アプリに入力しない運用としています。

2. Googleユーザーデータの取り扱い

本アプリは、利用者が「Googleアカウントと連携する」を選んだ場合に限り、次の権限を利用します。

  • https://www.googleapis.com/auth/calendar.app.created: 利用者のGoogleアカウントに専用カレンダー「NAORU TASK」を作成し、その中に利用者が担当するタスクの予定を作成・更新・削除します。また、利用者がその予定に行った完了操作（色や件名の変更）を読み取り、本アプリのタスクを完了にします。本アプリが作成したカレンダー以外のカレンダーや予定は、閲覧も変更もしません。
  • openid / email: 連携したGoogleアカウントのメールアドレスを確認し、別のアカウントへ誤って同期することを防ぐためにのみ使用します。

Googleのアクセストークンは利用者のブラウザのメモリ上でのみ使用し、サーバーや端末のストレージには保存しません。

本アプリによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（Limited Use 要件を含む）に従います。Googleユーザーデータを広告に利用したり、第三者に販売・提供したり、人が閲覧したりすることはありません（利用者本人の明示的な同意がある場合、セキュリティ上必要な場合、または法令に基づく場合を除く）。

3. 利用目的

  • タスクの登録・共有・進捗管理、期限の通知表示
  • 院長・管理者によるスタッフの業務状況の確認
  • 利用者のGoogleカレンダーへのタスクの反映
  • 不正利用の防止とセキュリティの確保

4. 保存場所と安全管理

データはSupabase（東京リージョン）に保存し、店舗ごと・権限ごとのアクセス制御（行レベルセキュリティ）により、他店舗の利用者や権限のない利用者が閲覧・変更できないようにしています。通信はすべてHTTPSで暗号化されます。

5. 第三者提供

法令に基づく場合を除き、利用者の情報を第三者に提供・販売することはありません。本アプリの提供のため、次のサービスを利用しています: Supabase（データベース・認証）、GitHub Pages（ウェブサイトの配信）、Google（カレンダー連携を利用する場合）。

6. 連携の解除・データの削除

  • Googleカレンダー連携は、本アプリの「設定」→「Googleカレンダー連携」→「連携を解除」でいつでも解除できます。解除時に、本アプリが作成した「NAORU TASK」カレンダーとその予定も削除されます。
  • Googleアカウント側からも Googleアカウントのサードパーティ アクセス設定 で、いつでもアクセスを取り消せます。
  • アカウントや業務データの削除をご希望の場合は、所属店舗の院長・管理者にお申し出ください。

7. お問い合わせ

本ポリシーおよび本アプリの情報の取り扱いに関するお問い合わせは、NAORU整体の院長・管理者までご連絡ください。

8. 改定

本ポリシーは必要に応じて改定することがあります。重要な変更がある場合は本アプリ内でお知らせします。

Summary (English)

NAORU TASK is an internal task manager for NAORU staff. If a user chooses to connect Google Calendar, the app uses the calendar.app.created scope only to create a dedicated "NAORU TASK" calendar and to create, update, delete, and read events in that calendar for the user's own tasks; it never reads or modifies any other calendar or event. The openid/email scopes are used only to confirm which Google account is connected. Access tokens are kept in browser memory and are not stored. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not sold, used for advertising, or shared with third parties. Users can disconnect at any time in the app or at myaccount.google.com/permissions.
